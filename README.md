# LifeOS 工作台 demo

这是 DataImmortality 的本地优先行动前台原型。它用于验证每天是否愿意打开、界面是否顺手，以及六个生活领域是否足够，而不是现在就建立完整产品。

## 手机 PWA 版本

- 在线地址：<https://skywalktx.github.io/lifeos-pwa/>
- 发布内容：不含个人记录的静态工作台外壳。
- 数据状态：填写内容仅保存在当前访问设备的浏览器中，尚未跨设备同步。
- 安装方式：Android 使用浏览器的“安装应用/添加到主屏幕”；iPhone 在 Safari 中选择“分享 → 添加到主屏幕”。
- 发布边界：这个目录是独立发布单元，不包含 Obsidian Vault、`raw`、日记或其他 DataImmortality 文件。

关于桌面 App、手机 PWA、网页仪表盘和零月费边界的选择，见 [`PRODUCT_DECISION_V0.1.md`](PRODUCT_DECISION_V0.1.md)。

v0.2 的六大领域、数据模型、AI Provider、安全边界与实施顺序，见 [`DESIGN_V0.2.md`](DESIGN_V0.2.md)。

## 打开方式

线上使用时直接打开 HTTPS 地址。本地预览可在 Windows 中双击 `start.cmd`，或直接用浏览器打开 `index.html`。

这个版本：

- 不需要账号、云服务器或付费订阅。
- 不加载外部字体、脚本、图片或统计代码。
- 填写内容仅尝试保存在当前浏览器的本地存储中。
- 可以在“本地数据”页导出和导入 JSON 演示快照。
- 不会自动读取或修改 Obsidian Vault。
- AI 区域可以接受问题并生成明确标注的本地演示响应，没有连接任何在线模型。
- 已包含 PWA 清单、主屏幕图标和离线缓存壳；需要通过 HTTPS 或 localhost 打开后才能启用安装与离线能力。

浏览器直接打开本地文件时，不同浏览器对持久化存储的行为可能不同。因此当前内容仅用于体验界面，重要内容仍需保存在 Markdown；演示状态可以手动导出为 JSON。

## 现在什么是真的，什么是演示

| 能力 | 当前状态 |
| --- | --- |
| 页面切换、领域编辑、复选框 | 可以实际操作 |
| 快速捕获 | 保存在当前浏览器，并在输入框下方显示回执和条目 |
| 回顾草稿 | 保存在当前浏览器；可以下载 Markdown 草稿 |
| JSON 导入导出 | 可以实际使用 |
| 手机桌面安装与离线打开 | 已有 PWA 壳；需要通过 HTTPS 或 localhost 提供页面 |
| 手机、工作电脑、家中电脑同步 | 尚未实现 |
| AI 问答 | 仅本地规则演示，不调用真正模型 |
| 自动写入 Obsidian Vault | 尚未实现 |

快速捕获成功后，应同时看到：

1. 页面底部短暂出现“已接住”的提示。
2. 输入框下方显示“已保存在当前设备，共 N 条”。
3. 新内容出现在输入框下方的列表中。

如果三项都没有出现，说明脚本没有正常运行，而不是内容已经悄悄保存。

## 已包含的体验

- 今日体验、晚间三步收尾和快速捕获。
- 快速捕获会显示当前设备保存回执和条目数量。
- 身体与健身、每日工作、英语、阅读、出行与旅行、杂务六个领域。
- 每个领域可以维护总览、可完成事项与带类型的领域日志。
- 最近七天按日期保存，不会在跨天后覆盖前一天记录。
- 事实、感受、明日一步与 AI 候选观察相互区分。
- 桌面、平板和手机宽度的响应式布局。
- 从回顾页下载符合项目来源规则的 Daily Markdown 草稿。

## 为什么改为手机优先 PWA

真实使用场景以手机为主，工作电脑可以使用浏览器但不适合安装应用。因此近期形态调整为手机优先 PWA：同一个界面可以在手机、工作电脑和家中电脑打开。

当前 demo 仍然只在每台设备本地保存。若要让多个设备看到同一份数据，就必须增加同步层；这与“能否做成网页”是两个不同问题。是否加入联网 AI 和同步服务，应当分别决定。

## 当前不是权威数据源

权威数据仍然是：

- `firstVault/Daily` 中的事实和每日记录。
- `firstVault/Notes` 中确认后的长期知识。
- `firstVault/Reviews` 中的周期回顾。
- `raw` 中不可覆盖的原始导入。

工作台负责“现在做什么”，不应取代这些长期存储。
